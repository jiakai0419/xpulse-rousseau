# Translation Prompt V2

## Purpose

Translate selected X posts into Chinese during refresh so the user can read the selected set immediately.

V2 aligns translation with Reader rendering: if a selected item is a repost/retweet, OpenAI translates the reposted source post, not the `RT @...` wrapper. The reposting account is provided only as timeline context.

## Model

Translations are generated by the configured OpenAI model, defaulting to shared `OPENAI_MODEL=gpt-5`, through structured JSON output. Live X refreshes must not use local translation. Missing OpenAI credentials, provider failures, unknown ids, or duplicate ids make the refresh fail visibly instead of saving substituted translation text. If a response only omits ids, the system may make one same-model repair request for the missing ids and records that request as normal OpenAI usage; an incomplete repair response still fails the refresh.

## Required Output Shape

```json
{
  "translations": [
    {
      "id": "string",
      "textZh": "string"
    }
  ]
}
```

The `id` remains the selected timeline item id, even when the translated content is the reposted source post.

## Quality Bar

- Translate faithfully instead of summarizing.
- Preserve the author's claim, uncertainty, tone, and emphasis.
- Preserve names, numbers, URLs, and technical terms when needed.
- Do not add background, judgment, or researcher interpretation.
- If the source post is already mostly Chinese, keep it as-is unless minor cleanup is needed.

## OpenAI Cache

Translation responses can be cached as OpenAI operation outputs. The cache key includes operation `translation`, requested model, prompt version `translation-v2`, and the post content fingerprint. It does not include ranking weights, selected count, author diversity, seen policy, or engagement metrics.
